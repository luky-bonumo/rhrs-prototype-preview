The one rule that carries the app

Coral is me

My character's name, my private notes, my recording, my line in a scene. If a control acts on me, it is coral.

Wine is everyone else

Other characters, stage directions, shared chrome, and any line the app reads to me. If it belongs to the scene, it is wine.

This is why the Listen and Rehearse transport changes colour mid-scene: it follows whoever currently holds the line.

Typography

Two typefaces

A serif for anything that names something — headings, character names, titles — and a humanist sans for everything you actually read. Two faces, no third: figures that count up or down are DM Sans with tabular numerals, which holds the digits still without bringing a monospace into the app.

Platypi sits low — trim it when you centre it

Platypi reserves far more room above its capitals than below the baseline. Anything that centres the text — a mode bar label beside its icon, a character name beside its note flags — centres that reserve along with the letters, and the type ends up riding low. It is not a bug in the font; it is what its metrics say. DM Sans is balanced and needs nothing.

The rule

Add .cap-trim to Platypi that is optically centred against something else. Leave running text alone — there the reserve is what gives paragraphs their rhythm, and trimming it would tighten the wrong thing. 

/* trims the box to cap-height..baseline, so centring lands on the letters */
.cap-trim { text-box: trim-both cap alphabetic; }

/* Firefox has not shipped it yet — same amount, applied by hand */
@supports not (text-box: trim-both cap alphabetic) {
  .cap-trim {
    display: inline-block;
    transform: translateY(calc(var(--cap-shift) * -1));
  }
}

In the prototype it is on: mode bar labels, character names, scene and list headers, and the settings sheet title.

For the Flutter build

This is not a CSS quirk — the same metrics produce the same drop in Flutter. Fixing it only here means it comes back in the app. Reach for TextHeightBehavior with leadingDistribution: TextLeadingDistribution.even, and expect to trim the same 0.092em wherever Platypi is centred beside an icon.

Icons

Every icon in the prototype

All icons are Phosphor, loaded as a web font. Markup is always <i class="ph ph-name ic-size"></i> — swapping an icon means changing the ph-* class and nothing else, since colour and size come from the surrounding CSS. Tap any tile to copy its class. Only icons actually used are listed here; browse the full set on the Phosphor site.

Controls · for review

Round controls, three weights

Glass is for the white surfaces. Anything carrying coral or wine drops it and takes a flat fill with a soft shadow in its own colour instead — the treatment the play/pause button already had. A tinted pane has nothing to read as glass; the colour is the weight.

/* white — glass */
background: rgba(255, 255, 255, 0.5);

/* + the 1.5px rim on ::before */

/* coral or wine — flat, no rim */
background: var(--coral);
box-shadow: 0 5px 18px rgba(239, 83, 80, 0.28);

One more rule, learned the hard way: a glass surface must carry no border. inset: 0 resolves against the padding box, so under a border the rim sits inside it and the fill paints as a ring outside — which is exactly the overlap that showed up on Script detail.

Components

Patterns that repeat

The handful of pieces that appear across screens. Everything else is composed from these.

Glass

Every raised surface — buttons, cards, lines, sheets — is the same three things: a half-transparent white fill, a soft shadow dropped down and right, and a 1.5px rim that catches light at the top-left and bottom-right and fades away through the middle. Nothing in the app is a flat white box. 

background: rgba(255, 255, 255, 0.5);
box-shadow: 2px 2px 8px rgba(224, 224, 224, 0.5);

/* the rim, as a masked gradient on ::before */
border-radius: inherit;
padding: 1.5px;
background: linear-gradient(135deg,
  #FFFFFF 20%, rgba(255,255,255,0) 50%, #FFFFFF 81%);
mask: linear-gradient(#000 0 0) content-box,
      linear-gradient(#000 0 0);
mask-composite: exclude;

Surfaces with a colour of their own — the wine card, a selected speed, the record button — keep that colour and take the rim only. Sheets sit over live content, so they add backdrop-filter: blur(20px), where the glass has something to bend.
